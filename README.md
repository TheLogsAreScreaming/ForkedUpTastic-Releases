# ForkedUpTastic Releases

Download builds of **ForkedUpTastic** here, from the [Releases](../../releases) page.

ForkedUpTastic is a fork of the Meshtastic Android app with extra features. The source code lives in [TheLogsAreScreaming/ForkedUpTastic](https://github.com/TheLogsAreScreaming/ForkedUpTastic) and is licensed under GPL-3.0. This repo only holds release files.

ForkedUpTastic is a modified version of the Meshtastic® Android app, changed by TheLogsAreScreaming since November 2026 (see [FORK_CHANGES.md](https://github.com/TheLogsAreScreaming/ForkedUpTastic/blob/main/FORK_CHANGES.md)). It works with Meshtastic® radios and installs beside the official app, which it does not replace.

ForkedUpTastic is not affiliated with or endorsed by the Meshtastic project. Meshtastic® is a registered trademark of Meshtastic LLC. Meshtastic software components are released under various licenses, see GitHub for details. No warranty is provided - use at your own risk.

## Installing

1. Download the `.apk` from the newest release.
2. Open it on your Android phone and allow installs from that source if asked.
3. Check the file against `SHA256SUMS` if you want to be sure it wasn't changed.

Report problems in this repo's Issues, not in the official Meshtastic repos.
